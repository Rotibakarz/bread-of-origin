# Setup Ranking System
Setups are ranked from 1 - 5 based on how useful they are to learn, the more often it can be ideally used and the stronger the setup is, the higher the rank it gets. This ranking does not take into account what test case you play in, so a setup that might be used often in tc3 ![[tc3.png|24]] will obviously not see any use in tc2 ![[tc2.png|24]].
#### 5 - Versatile setup that can be used often throughout the match, highly recommended to learn.
#### 4 - More conditional but strong setup that might not be used every match.
#### 3 - A setup that might not have great reward and/or weak mixup but still great add to your bag of tricks.
#### 2 - Usually a more gimmicky setup that might have counterplay or used in very niche situations.
#### 1 - Extremely niche, not practical/difficult to use
#### 0 - Meme setup
